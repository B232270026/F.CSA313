# Charter

## Судлах
"Уншлагын жагсаалт" веб аппын ном нэмэх, хайх, жагсаалт
харуулах, устгах болон API үйлдлүүдийг судална.

## Ашиглан
Хэвийн болон хоосон оролт, дутуу талбар, хязгаарын утга,
урт текст, том/жижиг үсгийн ялгаа, буруу JSON хүсэлт ашиглана.
UI-ийн үйлдлүүдийг браузераар, API-г curl ашиглан шалгана.

## Илрүүлэх
Оролтын баталгаажуулалт, хайлтын логик, давхардсан ном,
тоолуур, хүснэгтийн харагдац, мессеж, HTTP статус болон
алдаатай өгөгдөл боловсруулахтай холбоотой согогийг илрүүлнэ.

## Сонгосон аялалууд

- **Supermodel (GUI):** Номын жагсаалт, товч, хүснэгт,
  мессежийн харагдах байдал нь спецификацтай нийцэж байгаа
  эсэхийг шалгана.

- **Couch Potato (хоосон оролт):** Дутуу талбар болон хоосон
  утгуудыг ашиглан заавал бөглөх талбаруудын баталгаажуулалтыг
  шалгана.

- **Saboteur (API):** curl ашиглан буруу JSON болон хүчингүй
  өгөгдөл илгээж, API зөв HTTP статус буцааж байгаа эсэхийг шалгана.

- **Search Explorer (Хайлтын ажиллагаа):**
  Номын гарчиг болон зохиогчоор хайх,
  том/жижиг үсгийн ялгаатай оролтын үр дүнг
  харьцуулж, хайлтын логикийг шалгана.
