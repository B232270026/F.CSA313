# BUG-05: POST /api/books endpoint буруу JSON хүсэлтэд 200 OK буцааж байна

**Орчин:** Уншлагын жагсаалт v2.0, Firefox, Linux, 2026-10-20  
**Урьдчилсан нөхцөл:** `node app.js` командаар серверийг ажиллуулсан байна. Сервер `http://localhost:3000` хаяг дээр хүсэлт хүлээн авч байгаа.

## Дахин гаргах алхам

1. Терминал нээнэ.
2. Lab07 төслийн үндсэн хавтас руу орно.
3. `node app.js` командаар серверийг ажиллуулна. Хэрэв сервер аль хэдийн ажиллаж байгаа бол дахин асаах шаардлагагүй.
4. Шинэ терминал нээгээд дараах командыг ажиллуулна:

   ```bash
   curl -i -X POST http://localhost:3000/api/books \
     -H 'Content-Type: application/json' \
     --data '{invalid-json'
   ```

5. Терминалд гарсан HTTP статусын мөр болон хариуны body-г шалгана.

## Хүлээгдэж байсан үр дүн

`POST /api/books` endpoint нь JSON форматтай өгөгдөл хүлээн авах үед хүсэлтийн body-г шалгах ёстой. Буруу бүтэцтэй JSON илгээсэн тохиолдолд сервер хүсэлтийг татгалзаж, `400 Bad Request` HTTP статус буцаах ёстой. Буруу хүсэлтийг амжилттай боловсруулсан мэт `200 OK` статустай хариулах ёсгүй.

## Бодит үр дүн

Туршилтын үед дараах үр дүн ажиглагдсан:

- HTTP статус: `200 OK`
- Response body: `{"result":"OK"}`

Ингэснээр буруу JSON хүсэлтэд сервер амжилттай хүсэлт мэт хариу буцаасан.

## Ноцтой байдал

**Major** — API буруу форматтай оролтыг амжилттай хүсэлт мэт хүлээн авч байгаа нь оролтын баталгаажуулалт болон алдааны боловсруулалтад асуудал байгааг харуулж байна.

## Нотолгоо

- Бүтэн `curl -i` гаралт: `evidence/bug-05-curl.txt`
- Нотолгоонд `HTTP/1.1 200 OK` статусын мөр болон `{"result":"OK"}` хариу багтсан.

## Олдсон аялал

API-ийн оролтын баталгаажуулалт болон буруу хүсэлтийн алдааны боловсруулалтыг шалгах exploratory tour.

## Тэмдэглэл

Дахин шалгахдаа сервер ажиллаж байгаа эсэхийг баталгаажуулж, дээрх командыг яг хэвээр ажиллуулна. Серверийн хариу өөрчлөгдсөн бол бодит үр дүн болон нотолгооны файлыг шинэчилнэ.
