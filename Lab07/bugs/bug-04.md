# BUG-04: Номын хайлт том, жижиг үсгийг ялгаж байна

**Орчин:** Уншлагын жагсаалт v2.0, Firefox, Linux, 2026-10-20  
**Урьдчилсан нөхцөл:** `node app.js` командаар серверийг шинээр асаасан. Жагсаалтад `Software Testing Basics` гарчигтай, `John Smith` зохиогчтой ном бүртгэгдсэн.

## Дахин гаргах алхам

1. `http://localhost:3000/` хаягаар нэвтэрнэ.
2. `Бүгд` товчийг дарж `Software Testing Basics` ном жагсаалтад байгааг баталгаажуулна.
3. Хайлтын талбарт `Software Testing Basics` гэж оруулаад `Хайх` товчийг дарна.
4. Үр дүнг тэмдэглэнэ.
5. Хайлтын талбарыг цэвэрлээд `software Testing Basics` гэж оруулан дахин хайна.
6. Хайлтын талбарыг цэвэрлээд `SOFTWARE TESTING BASICS` гэж оруулан дахин хайна.
7. Үр дүнг харьцуулна.

## Хүлээгдэж байсан

Хайлтын шаардлагын дагуу том, жижиг үсгийн ялгааг үл харгалзан ижил номыг хайлтын үр дүнд харуулах ёстой.

## Бодит үр дүн

`Software Testing Basics` хайлтаар ном олдсон боловч `software Testing Basics` хайлтаар олдоогүй.

## Ноцтой байдал

**Major** — том, жижиг үсгийн ялгаанаас шалтгаалан хэрэглэгч бүртгэлтэй номыг хайлтаар олж чадахгүй байна.
