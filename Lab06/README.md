## 2. Ажлын зорилго

Category-Partition аргаар банкны шилжүүлгийн функцийн тестийн
сонголт, төлөөлөх утга, хязгаарлалт (IF/ERROR/SINGLE) болон тестийн спецификаци боловсруулах.

Microsoft PICT хэрэгслээр pairwise болон 3-way тестийн багц үүсгэж,
гараар боловсруулсан тестийн загвартай харьцуулах.
